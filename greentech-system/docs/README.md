# Greentech System

Hệ thống quản trị hạ tầng và xử lý nhật ký tự động.

## Cấu trúc thư mục
- `docs/`: Tài liệu kỹ thuật, hướng dẫn vận hành.
- `scripts/`: Tệp kịch bản tự động hóa (Shell/Batch).
- `data/`: Dữ liệu nhật ký hệ thống và danh mục tài nguyên.
- `backup/`: Bản sao lưu báo cáo sự cố và nhật ký.

## Hướng dẫn sử dụng
1. Đảm bảo cấu hình môi trường trong `.env`.
2. Chạy kịch bản trong thư mục `scripts/auto_report.bat` để tổng hợp báo cáo.
